# Tavily Web Search

Web search, page extraction, and site crawling via Tavily API.

## Tools

- **tavily_search** — Search the web for current information
- **tavily_extract** — Extract full content from URLs
- **tavily_crawl** — Crawl a website for broad content coverage

## Setup

Requires a [Tavily API key](https://tavily.com/). Set it via:

```bash
export TAVILY_API_KEY='your-key-here'
```

Or add `TAVILY_API_KEY='your-key-here'` to `~/.pi/.env`.
